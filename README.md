# Motorola Mobile Sales Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Motorola mobile sales performance, product performance, customer behavior, and sales trends.

The dashboard helps users understand sales performance across different cities, mobile models, brands, payment methods, and time periods.

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Excel

## 📈 Key KPIs

- Total Sales
- Total Quantity
- Total Transactions
- Average Customer Rating

## 🔍 Dashboard Analysis

The dashboard provides analysis of:

- Monthly Sales Trends
- City-wise Sales Performance
- Top Selling Mobile Models
- Brand-wise Sales Performance
- Brand-wise Quantity
- Payment Method Distribution
- Day-wise Sales Analysis
- Customer Rating Analysis
- Monthly Sales Filtering

## 💡 Key Insights

The dashboard provides an interactive view of Motorola mobile sales performance across different dimensions.

Users can analyze sales trends, compare product performance, identify top-performing cities and mobile models, and understand customer payment preferences.

Interactive filters allow users to explore the data according to different months and other available categories.
